Rescue Meal

A food inventory and meal planning assistant that tells you what to use first

In development, Service, Sep 2026 ~ Oct 2026

OpenOpen GitHub repository

Runs without a server, using sample ingredients and a sample receipt. Refreshing returns to the start.

The problem

A printed expiration date and how food has actually been stored are two different things. The app tracks them separately to keep food safe, with the goal of reducing waste.

What I did

  • Added ingredients via receipts, barcodes, and labels
  • Suggested meals built around the ingredients to use first
  • Included CodeQL and recovery drills in CI

Current status

  • As of October 2026, the TestFlight release flow is ready, and validation with real users has not been done yet.

Tech stack

  • Vite
  • Python
  • PostgreSQL
  • Docker Compose
  • GCP
Development log

How it started

A project to take a class deliverable to the level of a commercial app. It targets one- and two-person households who give up on inventory apps because adding ingredients is a hassle, and who miss the food they should eat first.

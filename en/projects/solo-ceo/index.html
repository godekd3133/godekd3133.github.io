Solo CEO

A back office that helps small business owners with grants and tax preparation

In development, Service, Sep 2026 ~ Oct 2026

Open

Runs without a server, using synthetic business data. Nothing is actually filed or submitted.

The problem

Running a shop on your own means missing grants you could receive and losing time to tax preparation.

For sole proprietors who handle grant searches and tax paperwork alone while running their business.

Key features

Grant condition checks

Business details are compared with each notice, showing per-item results and missing information.

Application prep

A checklist tracks documents, and you can resume an application at any time.

Sales and expense ledger

Enter records by hand or import CSV. Re-importing the same file creates no duplicates.

Tax document prep

Upload receipts, review categories and export by period.

Shared workspace

Invite members with roles. Notifications follow consent and delivery settings.

What I did

  • Implemented an Expo-based monorepo
  • Wrote the OpenAPI spec and a requirements traceability matrix
  • Drafted the service scope ahead of legal review, leaving out filing on a user's behalf

Architecture

One Expo app covers mobile and web, with API contracts kept in a shared package and an OpenAPI document.

  1. Client: Expo (React Native, web), shared UI package
  2. API: Python FastAPI, background workers
  3. Data: PostgreSQL with row-level access control, evidence file storage

Design decisions

Final calls belong to rules and people
AI helps extract and explain source text, while eligibility comes from versioned rules and human review, so AI output never reads like a confirmed result.
Four result states
Likely, needs information, unlikely and undetermined keep results distinct from an agency's final decision.
Official APIs only
Browser automation and storing credentials were ruled out. Filing and submission stop at preparation for the user to confirm.

Challenges and solutions

Requirements could easily end up only in UI copy or only in an API.
A traceability table links screens, APIs, data and checks, and CI flags missing entries.
An interrupted evidence upload left file status unclear.
Uploads record each step and expose a status lookup, so they can resume from where they stopped.

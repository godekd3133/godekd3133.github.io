SheedAI

A crowd battle game where you build decks and gear, then set out on expeditions

In development, Game, Aug 2023 ~ ongoing

The repository is private, so this page and its screenshots stand in for it.

The problem

The goal is to turn a paused prototype's combat into a progression structure worth returning to.

For single-player fans of deck building, large crowd battles and steady progression.

Key features

Crowd battles

Spend seeds to summon, merge and upgrade allies against enemy swarms.

Deck and gear setup

Choose one to six ally types plus a spirit and gear. The setup carries into battle.

Expeditions and growth

Clearing stages earns gold and new allies, then you level up and try again.

Keyboard support

On PC, Tab and Enter can select on-screen buttons.

What I did

  • Implemented card-deck crowd battles
  • Designed deck, gear, and expedition structure
  • Verified crowd combat in Unity

Current status

  • In development; the repository is private.

Architecture

It reuses the scenes and combat of a paused prototype and adds local progression rules on top.

  1. Client: Unity 2022.3, C#
  2. API: none (server features are out of scope)
  3. Data: on-device JSON save with backup, StreamingAssets content

Design decisions

Drop online features for local expeditions
With server code and temporary accounts mixed in, repeat play was unreliable, so the play and growth loop came first.
Apply currency changes only after a successful save
The order is copy, validate, write, swap. A failed save leaves currency and progress consistent.
Keep merge rules out of scenes
V11MergeRules is plain C#, so edge cases can be checked without a scene or a unit.

Challenges and solutions

At 90 units, some stalled while repeatedly searching for a path.
Retries are capped at four and only successful positions reach path calculation. NavMesh obstacle handling was also adjusted, then rechecked at 30, 60 and 90 units.
Icons finishing after a screen closed touched destroyed UI.
Each request now has a revision number, and stale results are ignored.

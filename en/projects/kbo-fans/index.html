KBO FansAI

A baseball fan app that shows your team's game right on your widget and lock screen

Beta (TestFlight), Service, Mar 2026 ~ Oct 2026

OpenOpen GitHub repository

Uses fictional players and synthetic game data, not real game records. The widget is an illustrative preview.

The problem

I brought today's scores and play-by-play text into widgets and Live Activities so you don't have to keep reopening the app to check them.

For KBO baseball fans who want their team's game status without reopening an app.

Key features

Home and lock screen widgets

Your team's game appears on the home and lock screens in several sizes.

Live Activity

Follow a game on the iOS lock screen and Dynamic Island.

Game detail

Score, play-by-play, box score and lineups sit in tabs, with filters for key moments.

Records

Leaderboards, two-player comparison and guides to reading stats.

Custom alerts

Choose results only, key moments or your own selection.

What I did

Current status

Architecture

The app talks only to the backend API, which handles refreshing and storing game information.

  1. Client: Flutter, Riverpod, go_router, SwiftUI widgets
  2. API: FastAPI, scheduler, FCM and APNs push
  3. Data: snapshot storage and caches on a single AWS Lightsail server

Design decisions

Four refresh classes for data
Live, short cache, stored snapshots and bundled assets. Finished games have no reason to be fetched again each time.
No direct fallback from the app
Two data paths make failures hard to trace. The app shows the last known state, and refreshes stay in the backend.
Start with one low-cost server
Lightsail fits tester-scale use, and ECS/Fargate stays available as the path for growth.

Challenges and solutions

Opening game detail for the first time could take several seconds.
Recent values are served first and refreshed in the background, and requests for live games warm the cache ahead of time.
A slow box score could also fail the lineup response.
The supporting request now runs separately with a short wait, so one no longer takes down the other.

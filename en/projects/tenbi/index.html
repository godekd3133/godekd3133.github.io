Rune Breaker: The Wizard's Dungeon

A 3D top-down hack-and-slash roguelite that runs in the browser

Playable demo, Game, Through Oct 2026 (including work before the repository move)

Play

The problem

Balancing a game you make on your own tends to come down to gut feel. So I built a tool alongside it for changing values right away.

What I did

  • Built toon-shaded 3D combat with Three.js
  • Created a separate balance console and balance service for tuning values
  • Created dedicated finales for 12 bosses and 24 new unique attacks
  • Collected about 170 findings across 8 areas and applied them starting with the highest-priority groups

Current status

  • Solo development using AI agents, continuing work moved over from v19~20

Tech stack

  • Three.js
  • Vite
  • drizzle

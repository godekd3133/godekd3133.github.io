Owning Both the Slot Server and Client

A year-by-year account of the period at Bagelcode in which I handled 14+ slot games, from server logic through the Unity client.

(Written in 2026, looking back.)

I joined Bagelcode in December 2021. My first task was adding features to the slot authoring tool, and in January 2022 I started implementing the server and client of a slot I was responsible for. This was when I began writing the server logic in TypeScript myself, on top of the Unity client.

My Scope

I implemented 14+ slots across Club Vegas Slots, Cash Billionaire, and Jackpot Madness. I wrote most of the server logic for my slots on my own and built the Unity client together with colleagues. Within a single slot, my work was divided like this:

  • Server: game logic and simulation
  • Client: reel behavior, state flow, animation, and presentation
  • Tools: improvements to the slot authoring tool’s editor and reel features

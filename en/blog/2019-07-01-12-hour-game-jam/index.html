What I Learned from 12-Hour Game Jams

Centered on the split viewport in What Up Buddy, a look at which implementations kept recurring across the games I finished in 12 hours.

(Written in 2026, looking back.)

In high school I kept entering events like AppJam, Highthon, the Korea Youth Game Jam, and my school’s own game jam. Teams of three or four had to finish a game in 12 hours. My 12-hour projects include What Up Buddy, Santa Overslept!, and a Cookie Run clone I made for personal study.

What Up Buddy (July 2019)

This is a quarter-view co-op game. Two people play the same game, so the screen had to be split.

The approach has three steps. Give each player a camera, then set each camera’s Target Texture to a Left or Right render texture. After that, the main camera films a scene with the two textures placed side by side.

The rest of the implementation was kept simple too.

  • Held items were managed with an enum, which split up their use effects.
  • CarSpawner picked each car’s direction and position at random, checked that it wouldn’t overlap another car in the same spot, and then spawned it.

Santa Overslept! (December 2019)

This is a side-scrolling casual arcade game. I managed the gift boxes in a single array, so spawning and input handling shared one data structure.

What Kept Repeating

Putting the two games side by side, similar choices show up again and again.

Recurring choice Where I used it
Singleton for managing game systems What Up Buddy, Santa
Object Pool for reusing objects Santa
Arrays and enums to keep data simple What Up Buddy, Santa

Even across different games I reused the same few methods, and for something I needed for the first time, like the split screen, I solved it with an engine feature such as render textures. Around this time I was also gaining experience sharing my code with other people.

A project where I took a bit more time is Ttangpaseo Donnaonya?! (Dig for Money?!), which I built in 20 hours and released in 2020. Later, in 2022, I took first place in the Entertainment category at the 20th AppJam.

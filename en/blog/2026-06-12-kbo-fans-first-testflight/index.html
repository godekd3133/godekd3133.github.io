Worklog: KBO Fans First TestFlight

The day I wrapped up releases 0.0.31 through 0.0.34. I got past a push deployment permission error, but testing on a real device is still outstanding.

This is the day of the first TestFlight release work. I’m including the work from the day before, June 11, as well.

What I Did

  • June 11: I tried a flow that deploys the push backend to AWS with GitHub Actions.
  • June 12: I wrapped up release 0.0.31. The path that updates regular push notifications and Live Activities even after the app is closed, along with the deployment script, is tied to this version in the CHANGELOG.
  • 0.0.32: I bumped the version to re-verify on TestFlight. I made My Team game-start notifications the default, and made Live Activities follow automatically when a live game is detected.
  • 0.0.33: I put the deployed backend address into the build so token registration goes to the real server, and I confirmed that the App Store Connect upload succeeded and processing had started.
  • 0.0.34: I made tapping a lineup notification open the game detail, and fixed a text broadcast bug.

What Blocked Me

On June 11, the CloudFormation deployment kept stalling on permissions. I found and added the service-linked role, the ALB security group lookup, the ECS role policy lookup, and the EFS network interface permissions one at a time. To make them easier to find, I first expanded the failure event logs and the output range. In the end I also fixed an EFS registry lock error.

On June 12, I couldn’t get as far as checking on a real device.

Decisions

  • To run a smoke test before connecting an HTTPS domain, I temporarily added an iOS ATS HTTP exception for that ALB address only. It is to be removed before final production.
  • For the parts I could check without a real token, I registered and unregistered a dummy token, then confirmed it had been cleaned up afterward.
  • Since I couldn’t check on a real device, I didn’t mark push verification as complete and listed it as remaining work.

What’s Left

Checking notification permission, real-device push, and Dynamic Island auto-start after installing from TestFlight, along with the HTTPS switch, were what remained that day.

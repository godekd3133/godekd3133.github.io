The KBO Fans Widget: Not Hiding Stale Scores

How the Flutter app and the iOS widget exchange data, how update delays are shown, and the widget bugs I fixed, based on the code.

KBO Fans is a baseball app I built so I could follow my team’s games without opening the app. I first added the iOS widget extension on March 30, 2026, and on May 20 I added deep links and the delay indicator.

Structure

On the Flutter side, WidgetSyncService fetches the scoreboard, picks which game to show, and writes the values to App Group storage. On the Swift side, WidgetKit only reads those values and draws them. In the background, a Workmanager task runs the same sync.

On iOS, a single widget draws differently by size: small, medium, and large, plus three lock screen variants. On Android, I registered a single-game widget and a today’s-games list widget separately.

Showing the Delay As It Is

The app can’t decide when WidgetKit refreshes; it can only request one. So the widget has to tell you when the score it shows was last updated. The label changes after 2 minutes for a game in progress and after 15 minutes otherwise.

let ageMs = Int64(Date().timeIntervalSince1970 * 1000) - updatedAtEpoch
let thresholdMs: Int64 = statusKind == "live" ? 2 * 60 * 1000 : 15 * 60 * 1000
if ageMs > thresholdMs {
  return "Update delayed \(updatedAt)"
}
return "Updated \(updatedAt)"

For the same reason, I don’t replace an unknown value with some other value. If there’s no pitch data, I hide balls, strikes, and outs instead of filling them in with 0. For a game whose source score is empty, I show – instead of 0:0.

Bugs I Fixed

Two of the widget bugs in the CHANGELOG were related to structure.

  • After a brief update failure, the widget didn’t refresh again with the same game data. This can happen because of the signature that is compared to skip identical content. The current code records the signature after the widget and Live Activity sync have finished.
  • A state where game data hadn’t been received yet was shown as a day with no games. I now distinguish the two states.

Career Center: Making You Answer the Same Question Again

The rule for picking one question to answer again from mock interview results, and the code that builds the reason sentence only from measured values.

Career Center is a job-hunting app that connects everything from choosing a posting to reviewing an interview. The comparison report has been there since the MVP, and on October 24, 2026, I moved answer-again up to the first button on the results, today, and practice screens. The related rules are collected in packages/core/src/retry.ts.

Which Question to Ask Again

pickRetryAnswer picks one using the AI evaluation already received. The order is:

  1. The answer the AI summary pointed to as needing improvement
  2. If none, the answer with the lowest sum of content score and fit score
  3. If there is no evaluation, the first answer

The threshold for recommending a retry is the constant RETRY_WEAK_BELOW = 80, and an answer where the user pressed “This evaluation is wrong” is not recommended.

The Reason Sentence Comes from Measurements

If the AI makes up “why you should answer again,” it’s hard to trust. So the reason sentence is built from measured values. The code below is shortened to the sentence part.

export function retryReason(a: AnswerRecord): string {
  const top = fillersCount(a) ? [...a.metrics.fillers].sort((x, y) => y.count - x.count)[0] : undefined;
  if (top && top.count >= 3) return /* "um" came up 5 times */;
  if (!a.typed && a.metrics.timeStatus === 'over') return /* time limit exceeded */;
  // check delivery, content, and fit scores in order
  return '';
}

A quote the AI picked is also used only when it appears in the actual answer with whitespace removed, in quoteOf.

If It Can’t Be Measured, Don’t Count It

Speech metrics are computed without AI by speech.ts. Browser speech-to-text sometimes erases “um, uh,” so filler habits and repetitions are counted only when the transcription is verbatim. Otherwise wordsMeasured becomes false and the result isn’t included in the score either.

What I Don’t Know Yet

I don’t know yet whether this loop actually improves interview skills. I checked the questions with AI virtual personas and have not yet validated them with real users.

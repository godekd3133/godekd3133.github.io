Sheed

덱과 장비를 편성해 원정을 떠나는 군중 전투 게임

개발 중, 게임, 2023년 8월 ~ 진행 중

저장소가 비공개라서 이 페이지의 소개와 화면으로 대신합니다.

풀려던 문제

중단된 프로토타입의 전투를 오래 즐길 수 있는 성장 구조로 잇는 것이 목표입니다.

덱을 짜고 몰려드는 군중 전투를 보며 조금씩 성장하는 재미를 좋아하는 싱글플레이 게이머를 위한 게임입니다.

주요 기능

군중 전투

씨앗을 써서 동료를 소환하고 합성, 강화해 적 무리와 맞붙습니다.

덱과 장비 편성

동료 1~6종과 정령, 장비를 골라 원정에 나갑니다. 편성이 실제 전투에 반영됩니다.

원정과 성장

스테이지를 깨면 골드와 새 동료를 얻고, 레벨을 올려 다시 도전합니다.

키보드 조작 지원

PC에서는 Tab과 Enter로 화면의 버튼을 고를 수 있습니다.

제가 한 일

  • 카드 덱 기반 군중 전투 구현
  • 덱과 장비 편성, 원정 구조 설계
  • Unity에서 군중 전투 동작 검증

현재 상태

  • 개발 중이며, 저장소는 비공개입니다.

구조

중단된 프로토타입의 씬과 전투를 살리고, 그 위에 로컬 진행 규칙을 얹었습니다.

  1. 클라이언트: Unity 2022.3, C#
  2. API: 없음(서버 기능을 범위에서 제외)
  3. 데이터: 기기 안 JSON 저장 파일과 백업, StreamingAssets 콘텐츠

설계 판단

온라인 기능을 빼고 로컬 원정으로 정리
서버와 임시 계정이 섞인 상태로는 반복 플레이가 믿을 만하지 않아, 플레이와 성장 루프의 신뢰성을 먼저 잡았습니다.
재화 변경은 저장에 성공한 뒤 반영
복사, 검증, 파일 저장, 교체 순서로 처리합니다. 저장이 실패해도 재화와 진행이 어긋나지 않습니다.
합성 규칙을 씬과 분리
V11MergeRules를 순수 C#으로 두어 씬이나 유닛 없이 경계값을 검증할 수 있게 했습니다.

어려웠던 점과 해결

90명 규모 전투에서 유닛이 길을 다시 찾느라 멈추는 현상이 있었습니다.
재시도를 최대 4회로 제한하고 성공한 위치만 경로 계산에 넘겼습니다. 또한 NavMesh 구조물 처리 방식을 조정해 30, 60, 90명 조건을 다시 확인했습니다.
화면이 닫힌 뒤 늦게 도착한 아이콘 로딩이 삭제된 UI를 건드렸습니다.
요청마다 번호를 매겨 이전 요청의 결과를 무시하게 했습니다.

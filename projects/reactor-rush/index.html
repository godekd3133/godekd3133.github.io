Reactor RushAI

적탄을 붙잡아 되쏘는 3D 액션 원정 게임

플레이 가능 데모, 게임, 2026년

플레이하기

새 화면에서 바로 실행됩니다. 일부 이미지는 AI로 생성했습니다.

풀려던 문제

탄을 피하기만 하는 대신 포획해 되돌려 주는 조작이 재미있으려면 입력 감각이 전부입니다. PC와 터치, 세로 화면까지 같은 손맛을 내도록 다듬었습니다.

한 손가락 조작부터 키보드와 마우스까지, 짧은 시간에 손맛 있는 3D 액션을 즐기고 싶은 플레이어를 위한 게임입니다.

주요 기능

적탄 포획과 반격

필드를 열어 적탄을 최대 12발 모은 뒤 다시 눌러 되돌려 줍니다.

퍼펙트 회피

공격 직전에 피하면 필살기가 차고 재사용 시간이 줄어듭니다.

예고가 분명한 보스전

탄막, 강타, 돌진을 바닥에 미리 표시하고, 공격 뒤 틈에 반격할 수 있습니다.

진화와 경로 선택

구역 사이에 진화와 다음 전투 경로를 골라 판마다 다른 구성을 만듭니다.

수집과 재대결

첫 탈환으로 무기와 외형을 얻고, 구성별 기록을 남기는 보스 재대결을 엽니다.

제가 한 일

  • 적탄 포획과 반사 조작 설계
  • PC와 터치 입력 양쪽 지원
  • 세로 화면 UX 정리

구조

서버 없이 브라우저에서 돌아가는 싱글플레이 게임입니다. 공격, 경로, 무기 규칙을 작은 모듈로 나눴습니다.

  1. 클라이언트: Three.js, TypeScript, Vite
  2. API: 없음(정적 빌드)
  3. 데이터: 브라우저 저장소의 원정 기록

설계 판단

입력을 발사될 때까지 보존
빠르게 톡 누른 입력이 쿨다운에 묻히면 조작이 씹힌 것처럼 느껴집니다. 사격 의도를 따로 저장해 발사가 수락될 때까지 유지했습니다.
첫 조작을 이동과 포획에 집중
처음부터 사격까지 맡기면 핵심 재미에 닿기 어려워 기본 자동 사격을 켜고 가장 큰 버튼을 포획에 배정했습니다.
공격과 경로 규칙을 데이터 계약으로 분리
화면 설명과 실제 판정이 어긋나지 않도록 UI와 전투가 같은 규칙 모듈을 읽게 했습니다.

어려웠던 점과 해결

세로 화면에서는 적이 카메라 밖으로 벗어나 찾기 어려웠습니다.
가장 가까운 화면 밖 적 하나만 가장자리에 표시해 전투를 가리지 않고 방향을 알려 줍니다.
화면을 눌러 조준할 때 경고 표시가 대상 선택을 가로챌 수 있었습니다.
실제 모델로만 대상을 판정하고 경고 표시는 제외해 보이는 적을 먼저 고르게 했습니다.

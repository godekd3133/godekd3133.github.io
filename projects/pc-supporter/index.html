풀려던 문제

부품 호환성은 맞다, 틀리다만 알려 주면 믿고 사기 어렵습니다. 판단 근거와 데이터의 출처를 함께 보여 주는 도구를 만들었습니다.

제가 한 일

  • 규칙 엔진으로 호환성을 검사하고 판단 근거를 설명
  • 한 줄 요구사항으로 견적을 자동 구성
  • 가격 추적과 조립 증거 기록 흐름 구현
  • 웹 서비스를 Capacitor로 감싸 모바일 앱으로 제공

현재 상태

  • 핵심 부품 115개, 주변 부품 10개 범주 42개의 starter catalog

사용 기술

  • React
  • Vite
  • Express
  • PostgreSQL
  • Capacitor
  • Docker
개발 기록

시작한 계기

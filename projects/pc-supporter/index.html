PC SupporterAI

내 견적이 왜 호환되는지 근거까지 보여 주는 PC 조립 도우미

라이브 베타, 서비스, 2026년 9월 ~ 진행 중

실행하기GitHub 저장소 열기

풀려던 문제

부품 호환성은 맞다, 틀리다만 알려 주면 믿고 사기 어렵습니다. 판단 근거와 데이터의 출처를 함께 보여 주는 도구를 만들었습니다.

처음 PC를 맞추면서 이 조합을 믿고 사도 되는지 근거까지 확인하고 싶은 사람을 위한 서비스입니다.

주요 기능

호환성 검사와 판단 근거

부품을 고르면 맞는지 여부와 함께 어떤 규격을 비교했는지 보여 줍니다.

한 줄로 시작하는 자동 견적

"QHD 게이밍 220만원, RAM 32GB"처럼 적으면 조건으로 풀어 보여 주고, 빠진 조건은 눌러서 채울 수 있습니다.

데이터 신뢰도 표시

가격 확인 여부, 스펙 누락, 벤치마크 출처를 부품과 함께 표시합니다.

구매 전 확인

호환 문제, 체크리스트, 가격 변화, 조립 기록을 한 화면에서 점검합니다.

조립 후 온도 기록

HWiNFO나 OCCT 센서 CSV를 넣으면 회차별 온도 변화를 같은 부하 조건끼리 비교합니다.

제가 한 일

  • 규칙 엔진으로 호환성을 검사하고 판단 근거를 설명
  • 한 줄 요구사항으로 견적을 자동 구성
  • 가격 추적과 조립 증거 기록 흐름 구현
  • 웹 서비스를 Capacitor로 감싸 모바일 앱으로 제공

현재 상태

  • 핵심 부품 115개, 주변 부품 10개 범주 42개의 기본 부품 목록

구조

웹과 서버가 호환 계산 코드를 함께 쓰고, 같은 웹 앱을 Capacitor로 감싸 모바일 앱으로 냅니다.

  1. 클라이언트: React, Vite, Capacitor(iOS, Android)
  2. API: Express, 호환·추천 엔진을 담은 shared/domain 공용 코드
  3. 데이터: PostgreSQL, 공개 상품 정보와 기본 부품 목록(핵심 115개, 주변 42개)

설계 판단

호환성, 데이터 신뢰도, 실제 조립 결과를 나눠 표시
개발 문서의 핵심 원칙입니다. 호환된다는 판정과 그 판정에 쓴 데이터가 믿을 만한지는 서로 다른 문제라서 한 점수로 합치지 않았습니다.
자동 추천은 후보와 비교까지만
위험이 남은 후보를 자동으로 적용하면 사용자가 근거를 볼 기회가 사라집니다. 그래서 미리보기 후 사용자가 직접 고르게 했습니다.
요구사항 해석을 규칙으로 처리
같은 문장은 늘 같은 조건이 되어야 결과를 믿을 수 있습니다. 해석 결과도 화면에 펼쳐 바로 고칠 수 있게 했습니다.

어려웠던 점과 해결

모바일에서 요청이 멈추면 화면이 끝없이 로딩되는 문제가 있었습니다.
요청마다 시간 제한을 두고 재시도하게 해 멈춘 요청에서 빠져나오도록 했습니다.
센서 CSV는 도구마다 열 이름이 다르고 기록 간격에 빈틈이 생깁니다.
열 이름을 자동으로 맞춘 뒤 적용 전 미리보기를 보여 주고, 시간 공백과 잘못된 값은 품질 카드로 알려 줍니다. 시계열은 최대 240개로 압축해 보관합니다.

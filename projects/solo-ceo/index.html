솔로사장

소상공인의 지원금과 세무 준비를 돕는 백오피스

개발 중, 서비스, 2026년 9월 ~ 10월

실행하기

서버 없이 합성 사업장 데이터로 체험합니다. 실제 신고나 신청은 이루어지지 않습니다.

풀려던 문제

혼자 가게를 운영하면 받을 수 있는 지원금을 놓치고 세무 준비에 시간을 빼앗깁니다.

본업에 집중하면서 지원금 찾기와 세무 자료 정리를 혼자 해야 하는 1인 사업자를 위한 앱입니다.

주요 기능

지원금 조건 비교

사업장 정보와 공고 조건을 비교해 항목별 결과와 부족한 정보를 알려 줍니다.

신청 준비

체크리스트로 서류를 챙기고 하던 신청을 이어서 합니다.

매출·지출 장부

직접 입력하거나 CSV로 가져오며, 같은 파일을 다시 넣어도 중복되지 않습니다.

세무 자료 정리

영수증을 올려 분류하고 확인한 뒤 기간별로 묶어 내보냅니다.

함께 쓰는 작업공간

구성원을 초대하고 역할을 나누며, 알림은 동의와 수신 설정에 따라 보냅니다.

제가 한 일

  • Expo 기반 모노레포 구현
  • OpenAPI와 요구사항 추적표 작성
  • 법률 검토 전 대행 범위를 제외한 초안 작성

구조

Expo 앱 하나로 모바일과 웹을 맡고, API 계약을 공용 패키지와 OpenAPI 문서로 관리합니다.

  1. 클라이언트: Expo(React Native, 웹), 공용 UI 패키지
  2. API: Python FastAPI, 비동기 작업 워커
  3. 데이터: PostgreSQL 행 단위 접근 제어, 증빙 파일 저장소

설계 판단

최종 판단은 규칙과 사람에게
AI는 원문 추출과 설명을 돕고, 자격 결과는 버전이 고정된 규칙과 사람의 확인으로 정합니다. AI 출력을 확정 자격처럼 보이게 하지 않으려는 결정입니다.
결과를 네 단계로 표시
기관의 최종 결정과 구분하려고 가능성 높음, 추가 정보 필요, 가능성 낮음, 판단 불가로 나눴습니다.
공식 API만 연동
브라우저 자동화나 인증수단 보관은 대안에서 뺐습니다. 신고와 제출은 준비까지만 돕고 사용자가 확인합니다.

어려웠던 점과 해결

요구사항이 화면 문구나 API 한쪽에만 남기 쉬웠습니다.
요구사항 추적표에 화면, API, 데이터, 검증을 함께 적고 누락을 CI에서 확인합니다.
증빙 업로드가 중간에 끊기면 파일 상태가 불분명해졌습니다.
업로드를 단계별로 기록하고 상태 조회를 두어 끊긴 지점부터 이어 가게 했습니다.

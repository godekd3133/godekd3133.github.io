작업일지: PC Supporter 메인보드 전원부 판정 변경

브랜치 병합으로 섞인 전원부 판정을 정리하고, 검증되지 않은 계수 대신 CPU 전력 등급과 보드 등급으로 판정하도록 바꾼 날입니다.

메인보드 전원부(VRM) 호환성 규칙을 다시 쓴 날입니다.

한 일

  • main을 기능 브랜치에 병합하며 충돌을 해결하고, 전체 페이즈 합계와 Vcore 페이즈 필드를 분리했습니다.
  • 병합 뒤 남은 전원부 판정의 문제를 정리했습니다.
  • 엔진을 2.63.0으로 올리며 판정 규칙을 바꿨습니다.
  • 병합 기록의 수치 오류를 정정했습니다.

막힌 것

두 브랜치가 같은 로직을 다른 방향으로 고쳐 두었고, 병합 결과에는 두 정책이 섞였습니다. “추정상 부족”과 “데이터 없음”이 같은 warning으로 나왔고, 전원부 표기가 없는 보드에는 65W급 CPU에도 경고가 붙었습니다. 코어 울트라 125W와 B860M 7페이즈 같은 흔한 조합이 부족으로 걸리기도 했습니다.

추정 계수도 약했습니다. 페이즈당 50A와 0.35는 실측으로 보정한 값이 아니었고, 페이즈 수는 표기 관행에 따라 의미가 달랐습니다.

충돌 표시 없이 생긴 문제도 있었습니다. 자동 병합으로 같은 필드 대입이 두 줄 생겨 한쪽 값을 덮어쓰고 있었습니다.

판단

  • 전원부 부족은 조립 불가가 아니라 고부하가 이어질 때의 전력 제한으로 나타납니다. 그래서 blocker는 제조사가 밝힌 용량이 초과될 때만 냅니다.
  • 검증되지 않은 계수로 와트를 추정하지 않습니다. 페이즈 수도 판정에서 뺐습니다.
  • 대신 칩셋을 보드 등급의 첫 신호로 씁니다. CPU 최대 전력 150W 이상과 보급형 보드가 만나면 warning, 보드 등급을 모르면 info입니다.

2026년 10월 2일 스냅샷 300건으로 비교하니 warning이 53건에서 28건으로, info가 6건에서 0건으로 줄었습니다. 남은 28건은 모두 보급형 보드와 고전력 CPU 조합입니다. warning과 info는 판정 상태에 영향을 주지 않아 상태 분포는 그대로였습니다.

남은 것

150W 기준과 Vcore 300A 하한은 실측 근거가 없는 임시값이라 앞으로 정해야 합니다. 인텔 K와 H810 조합의 등급, B840 같은 칩셋 추가, 보드 CPU 지원 목록 확보도 남아 있습니다.

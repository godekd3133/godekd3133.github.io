작업일지: Rescue Meal 사용 흐름 개선

홈, 식단, 장보기 흐름을 사용 순간별로 고친 날의 기록입니다.

Rescue Meal은 먼저 써야 할 재료부터 알려 주는 식재료 관리 앱입니다. 수업용 결과물을 고도화한 프로젝트이고, 대상은 등록이 번거로워 관리 앱을 포기한 1~2인 가구입니다. 이 날은 사용 순간별로 불편한 곳을 고치고 TestFlight 릴리즈 흐름을 정리했습니다. GS App을 띄워 점검한 일처럼, 기능 목록보다 쓰는 순서를 기준으로 봤습니다.

한 일

사용 순간 고친 것
첫 등록 영수증 없이 이름, 수량, 보관 위치만 입력
홈 냉장, 냉동, 실온 개수를 누르면 해당 목록이 바로 열림
식단 고르기 시간 상한을 엄격하게. 전에는 10분을 골라도 더 오래 걸리는 메뉴가 나옴
추천 점수 같은 재료를 나눠 등록하면 충족률이 100%를 넘던 계산을 레시피 재료 단위로 수정
구매 등록 보관 선택 전에는 저장 불가, 1000.5g 같은 소수도 그대로 저장

막힌 것

엄격해진 시간 조건 때문에 과거에 저장한 식단의 장보기 재계산이 실패했습니다. 저장된 같은 메뉴를 다시 계산할 때는 저장된 실제 조리시간을 허용해 해결했습니다. 별도 검토에서 재고 최신성과 이 호환 문제를 지적받아 고친 뒤 재검토를 통과했습니다.

새 추천

시간 상한을 엄격하게 지킵니다.

저장된 식단 재계산

이미 고른 메뉴이므로 저장된 실제 조리시간을 허용합니다.

확인한 것

추천, 식단, 장보기, 입고 흐름의 테스트와 새 화면 회귀 테스트를 돌려 이번 변경을 확인했습니다. 구매 경로는 실제 요청과 상세 화면으로 확인했습니다. 더 넓은 API 테스트에 남은 기존 실패는 이번 변경과 분리해 따로 처리하기로 했습니다.

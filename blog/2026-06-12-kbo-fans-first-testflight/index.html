작업일지: KBO Fans 첫 TestFlight

0.0.31부터 0.0.34까지 릴리즈를 정리한 날입니다. 푸시 배포 권한 오류를 넘겼지만 실기기 검증은 남았습니다.

위젯을 다듬은 뒤 첫 TestFlight 릴리즈 작업을 한 날입니다. 앞날인 6월 11일 작업까지 함께 적습니다.

한 일

버전 내용
6.11 GitHub Actions로 푸시 백엔드를 AWS에 배포 시도
0.0.31 앱 종료 후에도 일반 푸시와 Live Activity를 갱신하는 경로, 배포 스크립트
0.0.32 마이팀 경기 시작 알림을 기본으로, 라이브 경기 감지 시 Live Activity 자동 추적
0.0.33 배포된 백엔드 주소를 빌드에 넣어 토큰 등록이 실제 서버로 가게 함, 업로드 확인
0.0.34 라인업 알림에서 경기 상세로 진입, 문자중계 오류 수정

막힌 것

6월 11일 CloudFormation 배포가 권한 때문에 계속 멈췄습니다. 서비스 연결 역할, ALB 보안그룹 조회, ECS 역할 정책 조회, EFS 네트워크 인터페이스 권한을 한 번에 하나씩 찾아 추가했습니다. 찾기 쉽도록 실패 이벤트 로그와 출력 범위부터 늘렸습니다. 마지막에는 EFS 레지스트리 잠금 오류도 고쳤습니다.

6월 12일에는 실기기 확인까지 가지 못했습니다.

판단

배포 권한 오류로그 범위부터 확대더미 토큰으로 스모크 확인실기기 푸시는 미완료로 표시
  • HTTPS 도메인을 연결하기 전에 스모크 검증부터 하려고, 해당 ALB 주소에만 iOS ATS HTTP 예외를 임시로 넣었습니다. 최종 운영 전에 없앨 항목입니다.
  • 실제 토큰 없이 확인할 수 있는 부분은 더미 토큰으로 등록과 해제를 해 보고, 끝난 뒤 지워졌는지 확인했습니다.
  • 실기기 확인을 못 했으므로 푸시 검증을 완료로 표시하지 않고 남은 작업으로 적었습니다.

마지막 항목은 이후 완료 조건을 실행 결과로 바꾼 일과 같은 방향입니다.

다음에 할 것

TestFlight 설치 후 알림 권한, 실기기 푸시, Dynamic Island 자동 시작 확인과 HTTPS 전환이 이 날 남은 항목입니다. 8월 31일에 TestFlight 심사 승인을 받았습니다.

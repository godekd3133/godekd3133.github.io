PC Supporter 규칙 엔진: 모르면 모른다고 답하기

호환성 규칙 엔진이 판정 근거와 정보 부족을 어떻게 결과에 담는지, 실제 코드와 검증 결과로 설명합니다.

PC Supporter는 다나와 부품 카탈로그로 PC 견적의 호환성을 검사하는 서비스입니다. 맞다, 틀리다만 알려 주면 믿고 사기 어려워서, 판정마다 근거를 붙이는 구조로 만들었습니다. 엔진은 shared/domain/engine.ts에 있습니다.

판정 하나의 모양

규칙은 결과를 finding으로 남깁니다. 규칙 ID, 심각도, 영향받는 부품, 판정 사실, 사용자가 할 수 있는 행동이 함께 들어갑니다. 심각도는 blocker, warning, info, unknown으로 나눕니다.

정보가 없을 때 쓰는 addUnknown은 누락된 필드를 판정 사실로 넣고, 스펙을 확인하라는 행동을 붙입니다.

통과의 조건

완전 호환 판정은 unknown까지 없어야 나옵니다.

function isFullyCompatible(blockerCount: number, warningCount: number, unknownCount: number) {
  return blockerCount === 0 && warningCount === 0 && unknownCount === 0;
}

물리값이나 제조사 근거가 없으면 자동 통과로 올리지 않습니다.

데이터로 메운 부분

엔진이 unknown을 정직하게 내면 데이터가 비었을 때 unknown이 많아집니다. 10월 4일 작업에서는 파서를 고치고 제조사 원문으로 케이스 사양을 보강했습니다.

장착 조건도 판정에 넣었습니다. 검증에서 H6 Flow의 27mm 라디에이터는 후면 I/O 설치 조건이 확인되지 않아 unknown, 31mm는 제조사 한도 30mm를 넘어서 blocker가 나왔습니다.

남은 한계

위 표에 비어 있는 케이스가 남아 있습니다. 운영 데이터베이스에는 아직 반영하지 않았습니다. 메인보드 전원부 규칙은 추정 계수의 근거가 약해 이틀 뒤 판정 방식을 바꿨습니다.

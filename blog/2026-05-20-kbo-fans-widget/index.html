KBO Fans 위젯: 오래된 점수를 숨기지 않기

Flutter 앱과 iOS 위젯이 데이터를 주고받는 구조, 갱신 지연 표시, 위젯에서 고친 오류를 코드 기준으로 정리했습니다.

KBO Fans는 내 팀 경기를 앱을 열지 않고 보려고 만든 야구 앱입니다. iOS 위젯 확장은 2026년 3월 30일에 처음 추가했고, 5월 20일에 딥링크와 지연 표시를 붙였습니다.

구조

Flutter 쪽 WidgetSyncService가 스코어보드를 받아 표시할 경기를 고르고, App Group 저장소에 값을 씁니다. Swift 쪽 WidgetKit은 그 값을 읽어 그리기만 합니다. 백그라운드에서는 Workmanager 작업이 같은 동기화를 실행합니다.

iOS는 위젯 하나가 크기별로 다르게 그립니다. 소형, 중형, 대형과 잠금 화면 3종입니다. Android는 단일 경기 위젯과 오늘 경기 목록 위젯을 따로 등록했습니다.

지연을 그대로 보여 주기

WidgetKit의 갱신 시점은 앱이 정할 수 없고 요청만 할 수 있습니다. 그래서 위젯에 찍힌 점수가 언제 값인지 알려야 합니다. 진행 중인 경기는 2분, 그 외에는 15분이 지나면 문구를 바꿉니다.

let ageMs = Int64(Date().timeIntervalSince1970 * 1000) - updatedAtEpoch
let thresholdMs: Int64 = statusKind == "live" ? 2 * 60 * 1000 : 15 * 60 * 1000
if ageMs > thresholdMs {
  return "업데이트 지연 \(updatedAt)"
}
return "업데이트 \(updatedAt)"

같은 이유로 모르는 값을 다른 값으로 바꾸지 않았습니다. 투구 데이터가 없으면 볼, 스트라이크, 아웃을 0으로 채우지 않고 숨깁니다. 원천 점수가 비어 있는 경기는 0:0 대신 –로 표시합니다.

고친 오류

CHANGELOG에 남은 위젯 오류 가운데 구조와 관련된 것이 둘 있습니다.

  • 갱신이 잠시 실패한 뒤 같은 경기 정보로 다시 갱신되지 않았습니다. 같은 내용이면 건너뛰려고 비교하는 서명이 있어서 생길 수 있는 문제입니다. 지금 코드는 위젯과 Live Activity 동기화가 끝난 뒤에 서명을 기록합니다.
  • 아직 경기 정보를 받지 못한 상태를 경기 없는 날로 표시했습니다. 두 상태를 구분했습니다.

슬롯 서버와 클라이언트를 함께 맡은 일

베이글코드에서 슬롯 14종 이상을 서버 로직부터 Unity 클라이언트까지 맡아 온 기간을 연도별로 정리했습니다.

(2026년에 돌아보며 쓴 글입니다.)

2021년 12월에 베이글코드에 합류했습니다. 첫 작업은 슬롯 제작 도구에 기능을 추가한 것이었고, 2022년 1월에 처음으로 담당 슬롯의 서버와 클라이언트 구현을 시작했습니다. Unity 클라이언트에 더해 서버 로직까지 TypeScript로 직접 쓰게 된 것이 이 시기입니다.

맡은 범위

Club Vegas Slots, Cash Billionaire, Jackpot Madness의 슬롯을 14종 이상 구현했습니다. 담당 슬롯의 서버 로직은 주로 혼자 작성하고, Unity 클라이언트는 동료와 함께 구현했습니다. 슬롯 하나 안에서 맡은 일은 이렇습니다.

  • 서버: 게임 로직과 시뮬레이션
  • 클라이언트: 릴 동작, 상태 흐름, 애니메이션, 연출
  • 도구: 슬롯 제작 도구의 에디터와 릴 기능 개선

게임 개발2019.07.01

12시간 게임잼에서 배운 것

What Up Buddy의 뷰포트 분할을 중심으로, 12시간 안에 끝낸 게임들에 어떤 구현이 반복되었는지 정리했습니다.

(2026년에 돌아보며 쓴 글입니다.)

고등학교 때 앱잼, 하이톤, 대한민국 청소년 게임잼, 교내 게임잼 같은 행사에 꾸준히 나갔습니다. 3~4명이 12시간 안에 게임 하나를 끝내야 하는 자리였습니다. 12시간 작품으로는 What Up Buddy, 산타가 늦잠 잤다!, 쿠키런 모작(개인 학습용)이 있습니다.

What Up Buddy (2019년 7월)

쿼터뷰 협동 게임입니다. 한 게임을 두 명이 조작해야 해서 화면을 나눠야 했습니다.

방법은 세 단계입니다. 플레이어마다 카메라를 하나씩 붙이고, 각 카메라의 Target Texture를 Left와 Right 렌더 텍스처로 지정합니다. 그다음 메인 카메라가 두 텍스처를 좌우로 놓은 장면을 찍습니다. 그 밖의 구현도 단순하게 갔습니다.

  • 보유 아이템은 열거형으로 관리해 사용 효과를 나눴습니다.
  • CarSpawner는 자동차의 방향과 위치를 무작위로 정하고, 같은 자리에 겹쳐 나오지 않는지 확인한 뒤 생성했습니다.

산타가 늦잠 잤다! (2019년 12월)

횡스크롤 캐주얼 아케이드입니다. 선물상자를 배열 하나로 관리해 생성과 입력 처리를 같은 자료구조로 끝냈습니다.

다시 보면 반복된 것

두 작품을 나란히 놓으면 비슷한 선택이 반복됩니다.

반복된 선택 쓴 곳
Singleton으로 게임 시스템 관리 What Up Buddy, 산타
Object Pool로 오브젝트 재사용 산타
배열과 열거형으로 데이터를 단순하게 유지 What Up Buddy, 산타

작품이 달라도 같은 방법 몇 개를 되풀이해 썼고, 화면 분할처럼 처음 필요한 기능은 렌더 텍스처 같은 엔진 기능으로 풀었습니다. 이 무렵 제 코드를 다른 사람과 나눠 쓰는 경험도 쌓았습니다.

조금 더 시간을 쓴 사례로는 20시간 만에 만들어 2020년에 출시한 땅파서 돈나오냐?!가 있습니다. 이후 2022년에는 20회 앱잼 엔터테인먼트 부문에서 1등을 했습니다.

AI2026.11.02

AI에 구현을 맡기면서 시장을 더 보게 됐습니다

구현을 AI에 맡기기 시작하면서, 제게 더 중요해진 질문은 어떻게 만드느냐보다 무엇을 만들어야 시장에서 통하느냐입니다.

저는 오랫동안 기술로 제 가치를 설명했습니다. 고등학교 때는 엔진 없이 DirectX로 프레임워크를 짰고, 회사에서는 슬롯의 서버 로직과 Unity 클라이언트를 함께 구현했습니다. UniTask 도입이나 릴 시스템처럼 더 나은 구현을 고민하는 일이 곧 성장이라고 생각했습니다.

2026년 7월 무렵부터 업무 전반을 AI에 맡기기 시작하면서 이 생각이 바뀌었습니다.

무엇이 달라졌나

이전에 어려웠던 것

이 기능을 어떻게 구현할까. 어떤 구조가 더 빠르고 안전할까.

지금 더 어려운 것

이것을 만들 가치가 있을까. 누가 왜 쓰고, 시장에서 통할까.

기술이 중요하지 않게 됐다는 뜻은 아닙니다. 결과를 판단하고 검증하려면 기술을 알아야 합니다. 다만 구현에 드는 시간이 줄어든 만큼, 제가 하는 일의 무게가 다른 곳으로 옮겨 갔습니다. 무엇이든 빠르게 만들 수 있게 되자, 잘못된 것을 빠르게 만드는 일도 쉬워졌기 때문입니다.

기술 도메인에서 시장 도메인으로

구현을 AI에 위임만드는 비용 감소무엇을 만들지가 병목시장 가설을 먼저 검증

그래서 제가 키워야 할 전문성도 달라졌다고 생각합니다. 어떤 기술을 쓰느냐만큼, 어떤 상품이 시장에서 성공하는지 이해하고 그것을 효율적으로 개발하는 능력이 중요해졌습니다.

이 변화는 최근 작업에서도 드러납니다.

작업 먼저 고민한 것
사내 신규 게임 탐색 후보를 여럿 만들어 근거를 비교한 뒤 하나에 집중
슬롯 개발 워크플로 팀이 같은 기준으로 더 빠르게 신규 슬롯을 시도하는 방법
개인 제품 누구의 어떤 문제를 푸는지, 실제 사용자로 어떻게 검증할지

앞으로의 방향

저는 게임 개발자로서 기술을 계속 쌓아 가되, 시장에서 통하는 상품을 효율적으로 만드는 사람이 되고 싶습니다. 아직 시장에서 크게 검증받은 개인 제품은 없습니다. 그래서 다음 목표는 더 많이 만드는 것이 아니라, 하나를 시장에 내놓고 반응을 확인하며 고쳐 나가는 경험입니다.
